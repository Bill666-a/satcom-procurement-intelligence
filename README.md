# 星链研判 · 招标情报中枢

这是一个可本地运行的卫星通信招标情报工作台，包含：

公网网站：<https://bill666-a.github.io/satcom-procurement-intelligence/>

- 中国政府采购网公开页面采集器
- 全国公共资源交易平台官方历史查询接口（覆盖其汇聚的省平台、央企招投标、财政部等公开数据源）
- 中国招标投标公共服务平台状态适配器
- 浙江省公共资源交易服务平台官方全文检索与公告详情适配器
- 山东省政府采购信息公开平台官方检索与公告详情适配器
- 关键词命中与“应急通信 + 卫星/卫通”规则
- 项目链接去重与 JSON 持久化
- 项目查询 API
- 手动增量更新
- 每天 00:00 自动增量采集
- 前端看板、项目库、详情抽屉和 CSV 导出

## 启动

在项目目录运行：

```powershell
npm run start
```

打开：<http://127.0.0.1:4173/>

启动服务后不会重复触发采集，避免来源站点因频繁访问而限流。可以点击页面中的“立即更新”，或使用命令执行采集。

## 发布为公网网站

当前仓库已配置 GitHub Pages。推送到 `main` 分支后会自动构建并发布，GitHub Actions 还会在每天北京时间 00:00 执行公开数据采集并重新部署。

项目已提供 `Dockerfile` 和 `render.yaml`，可部署到 Render 等支持 Docker 和持久磁盘的云平台。部署时使用 `render.yaml` 创建 Web Service，并绑定 1 GB 持久磁盘；平台会自动提供公网 HTTPS 地址，手机和其他网络的用户可直接打开。

公网环境使用以下设置：

- `PUBLIC_DEPLOYMENT=true`：访客只能浏览，不能匿名触发采集；
- `DATA_DIR=/var/data`：项目数据和来源缓存写入持久磁盘；
- `HOST=0.0.0.0`：监听云平台网络；
- 平台通过 `PORT` 注入服务端口，不能固定写死端口。

首次发布后会自动把仓库中的 `data/projects.json` 导入持久磁盘。之后由服务每天 00:00 自动执行增量采集。Render 的持久磁盘属于付费 Web Service；如果使用没有持久磁盘的免费实例，网站仍可打开，但重启后新增采集数据可能丢失。

管理员在公网手动采集时，可设置 `COLLECT_TOKEN`，然后携带 `Authorization: Bearer <token>` 调用 `POST /api/collect`。不要把令牌写入前端页面。

## 首次历史回溯

首次需要回溯 2025-01-01 至当天时运行：

```powershell
npm run collect
```

这会从 `2025-01-01` 开始分批访问多个国家级公开平台，并将结果写入 `data/projects.json`。每次只处理一个日期窗口，重复执行 `npm run collect` 会从上次断点继续，直到历史回溯完成。

## API

- `GET /api/health`：查看服务和最近采集状态
- `GET /api/projects`：读取项目数据
- `GET /api/projects?q=卫星终端`：按关键词查询
- `GET /api/projects/:id/source`：低频访问并缓存项目公开来源，限流时返回说明页
- `POST /api/collect`：提交增量采集任务
- `POST /api/collect`，请求体 `{ "full": true }`：提交历史回溯任务

“全网”在本系统中指已登记的公开来源集合，不包含登录后、验证码后、付费墙后或非公开内容。地方政府采购网、地方交易中心和央国企平台数量很多，需要继续登记其公开入口或使用其官方接口；全国公共资源交易平台本身已汇聚其中一部分公开数据。

## 合规边界

采集器只访问公开页面，不处理登录、验证码、付费墙、非公开资料或绕过访问限制的操作。当前已实际执行采集的来源为中国政府采购网、全国公共资源交易平台、中国招标投标公共服务平台状态适配器、中国邮政电子采购与供应平台、浙江省公共资源交易服务平台和山东省政府采购信息公开平台。其余目录来源仍需逐一确认公开检索接口后再适配，并遵守对应网站的 robots、服务条款和访问频率要求。

当前运行环境如果无法解析外网域名，服务会保留上一次已采集数据，并在 `/api/health` 中记录失败原因；前端不会回退到演示或虚构记录。

如果来源站点触发访问频率限制，健康状态会显示为 `partial`，表示本次只完成了部分页面；程序会保留已有数据，不会把部分结果伪装成完整历史结果。等待一段时间后再次执行即可。
